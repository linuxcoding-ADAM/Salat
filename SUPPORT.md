# Getting help

- **Installing or running Salat:** [`docs/INSTALL.md`](docs/INSTALL.md),
  [`docs/CONFIGURATION.md`](docs/CONFIGURATION.md) and
  [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md).
- **Known problems** (including the systemd unit): [`docs/KNOWN_ISSUES.md`](docs/KNOWN_ISSUES.md).
- **A bug:** [open an issue](https://github.com/linuxcoding-ADAM/Salat/issues/new/choose)
  with the bug report form.
- **A feature idea:** open an issue with the feature request form.
- **A vulnerability:** do not open an issue. See [`SECURITY.md`](SECURITY.md).
- **Contributing code:** [`CONTRIBUTING.md`](CONTRIBUTING.md).

Salat supports Linux on x86_64 only (ARM64 is planned). Native Windows and
macOS are not supported, and WSL2 is not officially supported. Issues and
pull requests live on GitHub: <https://github.com/linuxcoding-ADAM/Salat>.
There is no GitHub CI status on pull requests; see
[`CONTRIBUTING.md`](CONTRIBUTING.md#sending-a-pull-request).
