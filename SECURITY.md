# Security policy

## Supported versions

Only the latest release receives security fixes. The current release is
**v0.1.0**.

## Reporting a vulnerability

Please report vulnerabilities **privately**, using GitHub's private
vulnerability reporting:

<https://github.com/linuxcoding-ADAM/Salat/security/advisories/new>

Do **not** open a public issue or pull request, or post details anywhere
public, for a vulnerability that could be exploited. Include the Salat
version, what an attacker could do, and steps to reproduce.

This is a volunteer project. There is no guaranteed response time, but
reports are read and answered as soon as possible, and a fix is released
before details are published.

## Scope

Salat is a local terminal program that talks to the AlAdhan API. Reports
about the installer (`install.sh`), the release artifacts, the systemd unit
and the handling of configuration and data files are in scope. Known
defects that are not vulnerabilities are listed in
[`docs/KNOWN_ISSUES.md`](docs/KNOWN_ISSUES.md).
